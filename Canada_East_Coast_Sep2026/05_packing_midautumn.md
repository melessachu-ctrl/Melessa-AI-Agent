# 05 — 衣著清單＋中秋飯時間緩衝

## 天氣（9 月中下旬・多倫多／尼加拉）

- 日間約 **18–24°C**，早晚約 **12–15°C**  
- 偶有雨；尼加拉湖邊／船上風大、有水花  
- 策略：**層次穿著**，一件可收納的防水外套必帶

---

## 每人行李清單（打勾）

### 日用
- [ ] 短袖 3–4  
- [ ] 薄長袖／襯衫 2–3  
- [ ] 長褲／牛仔褲 2–3  
- [ ] 舒適步行鞋（防滑；父母優先）  
- [ ] 薄襪足夠天數  

### 保暖／防風雨
- [ ] **防風防水外套** 1（船上／下雨）  
- [ ] 薄毛衣或抓毛 1–2  
- [ ] 摺疊傘  
- [ ] 小圍巾（冷氣／船上）  
- [ ] 太陽眼鏡  

### 回程中秋（隨身袋）
- [ ] 一件較整齊外套或換洗衣物（飛機落地後可能直接赴飯局）  
- [ ] 個人藥物、眼鏡、充電器  
- [ ] 護照、eTA 確認截圖、機票、酒店確認  

### 其他
- [ ] 轉換插頭（加拿大 Type A/B）  
- [ ] 行動電源  
- [ ] 少量加幣或主要靠信用卡（小費 15–20%）
