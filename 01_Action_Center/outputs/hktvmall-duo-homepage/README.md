# HKTVmall homepage on iPhone Duo

Interactive mockup of the 今日格價榜 homepage, adapted to iPhone Duo using Apple Tech Talk 111466 / 111462 rules.

## Files

| File | What it is |
|---|---|
| `duo-mockups.html` | Source mockup. Open in a browser. `?view=outer` / `?view=inner` / `?view=board` |
| `duo-homepage-outer.png` | Chrome capture of the outer (5.4") Compact layout |
| `hktvmall-duo-outer-render.png` | Rendered 效果圖 · 外屏 |
| `hktvmall-duo-inner-render.png` | Rendered 效果圖 · 內屏 |

## Layout rules used

- **Outer Compact:** search / 分類 / camera stay horizontal. House + CS + 6 tabs move to a right vertical system bar. No bottom tab bar.
- **Inner Regular:** same 6 destinations become a sidebar. Content splits list + product. House + CS stay on the trailing system bar.
- Tab order is unchanged: 我的清單 → ChicChat → 減價優惠 → 今日格價榜 → 購物車 → 帳戶／設定
