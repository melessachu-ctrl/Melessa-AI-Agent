# Tonight Dinner（今晚煮咩好？）

## 載入時機（必遵守）
命中下列**任一**情況時，必須載入並依本 skill 執行（不可略過、不可改用其他格式）：
- 使用者直接說：今晚煮咩好？／今晚煮乜好？／今晚食咩／晚餐（可加菜系關鍵字）
- 使用者先叫 **Sasa／Personal AI Assistant**，再請佢出晚餐／煮咩／一餐建議
- 使用者只丟菜系關鍵字（例如「韓式」）且語境係今晚／晚餐

執行前：先讀同目錄 `memory.md`（有就用；冇就跳過），再按下方輸出格式出齊。

## 目標
用你家煮食工具（一般鍋和鑊、蒸焗爐、電飯煲）在**60分鐘內**做出一餐：營養均衡、少油少鹽、不重口味，並且**高蛋白**（兩位都有健身/運動習慣）。

## 份量規格（必遵守）
- 做成「2人份」並清楚標示：
  - 丈夫（75kg）：按一般男士食量計（份量係數=1.0）
  - 妻子（48kg）：偏少（份量係數=0.64；約=48/75）
- 所有用料（特別係蛋白質：雞/魚/蝦/豆製品/蛋）都要按比例調整，唔可以淨係寫「兩人份」而無明確量。

## 選菜規則（讓料理可做到、可上菜）
1. **主菜 + 配菜 + 主食**（或主菜＋湯，但總數以 2–3 個菜為主，確保可同時上菜）
2. 工序要能「分工 + 同時進行」：
   - 主食用電飯煲或可同時進行嘅步驟
   - 蛋白質用快煮：雞胸/雞腿去皮、蝦、白魚、瘦豬/牛、豆腐（最好可烤/蒸/快炒）
   - 配菜用蒸/焗/快炒（少油策略：水炒/少量油煎、用蒜蓉/香草提味）
3. **少油少鹽不重口味**：
   - 優先用：蒸、焗、快炒少油、檸檬/醋/香草、香料（黑胡椒、薑、蒜、蔥）
   - 鹽/醬調味用「建議用量」，並附「如果口味較淡：點調」小技巧
4. **食材容易買到/取得**：
   - 優先用一般超市常見食材
   - 若用到較少見（如某特定醬），必須附「替代品」與替代效果描述

## 可選：讀取「廚房記憶」（有就用；冇就跳過）
同目錄讀取並考慮：`memory.md`
- 你要優先避免重覆同一主菜太密（例如同類蛋白/同類醬汁可略重覆，但主菜菜式唔好重覆到令人膩）
- 若記憶有「忌口/唔食」：必須遵守

## 需求不足時最多問 1–2 題（不可以問太多）
只有以下情況先問：
- 有冇過敏/明確唔食嘅食材？
- 有冇素食/宗教限制？
除呢兩類，寧願先用預設（正常全食、無過敏）直接開工。

## 輸出格式（每次都照呢個順序、全部出齊）
1. **今晚一餐（菜單總覽）**
   - 菜式名（含菜系；如果用戶有指定菜系就用）
   - 每個菜一句：口感/重點
2. **2人份份量表（丈夫 vs 妻子）**
   - 以克數/數量列出（例如：雞胸XXg、米XXg、豆腐半塊/一塊）
3. **60分鐘時間軸（同時上菜）**
   - 用「T+0、T+10、T+20…」列出工序節點
   - 每個節點講清楚「邊樣煮緊」以及「下一步要準備咩」
4. **食材清單（附替代品）**
   - 分組：主食 / 主菜蛋白 / 配菜 / 湯/醬汁
   - 每組至少 1 個替代建議（即使唔需要買亦要寫）
5. **詳細食譜（逐步、可照做）**
   - 每個菜：
     - 所需時間（目標分鐘）
     - 步驟 1→N（每步寫：做咩 + 需要注意咩火候/狀態）
     - 少油少鹽策略：一段話（例如：用醬汁先拌入、最後才收汁、鹽用量上限）
6. **營養均衡與高蛋白估算（粗略即可）**
   - 蛋白質：丈夫/妻子估算（g）
   - 其他宏量營養：大概比例（例如：高蛋白、適量碳水、低脂/中脂）
   - 少油少鹽說明：你用咩方法把鹽油控到位
7. **圖示（必須附）**
   - 每個菜至少提供 1 張「成品擺盤圖示」
   - 再提供 1 張「關鍵步驟示意」（例如：焯水/醬汁拌勻/包裹下鍋/蒸焗狀態）
   - 圖示內容要求（每張都要有）：
     - 清楚看到食材形狀/顏色
     - 以繁體中文在圖中標短詞（例如「少油快炒」「蒸到熟透」），避免長篇文字

## 圖示輸出格式（模型/工具用；務必照抄）
對每個菜，請輸出兩段「圖示提示」，每段都要有「用途 + 畫面描述 + 圖中短詞」：
- 圖示1（成品擺盤）：用途：...；畫面描述：...；圖中短詞：...
- 圖示2（關鍵步驟）：用途：...；畫面描述：...；圖中短詞：...

8. **（可選）記憶更新確認**
   在出完菜譜後，先用一句問你：「想唔想把今晚呢個菜式記入 memory.md（避免下次重覆）？」
   - 你只要回答「記入」就好；若回答「唔使」，就唔好改檔案。
   - 若記入：把「主菜名 + 大概口味（少油少鹽/蒜香/清新檸檬）」加進 `recent`（例如置頂一行，保留最新 5 次即可）。

## 圖示生成指令（給模型/工具使用）
如可用圖像生成工具，按下列規格產圖：
- 構圖：餐桌俯視或 45 度斜角，突出菜品層次
- 光線：自然光、清晰、非暗房
- 背景：簡潔廚房木桌/白底（唔要花紋過密）
- 必要標註（圖中短句）：每張 3–6 字內
